# Forgex Raw — one-knob track finisher

![Forgex Raw](https://raw.githubusercontent.com/RemiBlaze/ForgexRaw/main/forgexraw-ui-screenshot.png)

**One knob that finishes any track.**

Forgex Raw is the free, one-knob version of **Forgex**. Turn the single **POLISH** knob and any track gets a finished sound — warmth, air, width, and glue in one move — all level-matched so it sounds better, not just louder.

Fully **signed and notarized** for macOS as **AU, VST3, and Standalone**.

## 🚀 Download & Install
1. Go to the [latest release](https://github.com/RemiBlaze/ForgexRaw/releases/latest).
2. Download **`ForgexRaw_Installer.pkg`**.
3. Double-click it and follow the installer. Signed & notarized by Apple — installs cleanly, no security warnings.
4. Restart your DAW and rescan plug-ins.

Full guide: **[remiblaze.com/support](https://remiblaze.com/support/)**.

## 🎛️ What It Does
One big **POLISH** knob drives the whole "finish a track" chain at once, front-loaded and level-matched:

- **Warmth** — smooth tanh saturation for gentle analog-style glue.
- **Air** — a tilt EQ that lifts the highs (pivot ~650 Hz) as you push the knob.
- **Width** — a gentle stereo widen above unity, with the lows kept mono so the bass never smears.
- **Glue** — a fast-attack limiter that holds it together and keeps a safe ~0 dBFS ceiling.
- **Level-matched** — output is trimmed as you drive so louder isn't fooling you.

At **0** it's clean and transparent. That's the whole plugin — turn it up until it sounds finished.
